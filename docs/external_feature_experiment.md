# 공휴일·기상 변수 보충 실험

## 실험 원칙

- 학습: 2024-01-01~2025-12-31
- 검증: 2026-01-01~2026-05-31
- 보관 시험: 사용하지 않음
- Random Forest 설정은 동일하게 고정하고 공휴일·기상 변수 추가 여부만 비교

## 회귀 성능

| 모델 | MAE | WAPE | RMSE |
|---|---:|---:|---:|
| 공휴일·기상 추가 Random Forest | 35.71 | 6.10% | 77.21 |
| 기존 입력 Random Forest | 36.00 | 6.15% | 77.73 |

## 고교통량 경보 성능

| 모델 | Precision | Recall | F1 | PR-AUC |
|---|---:|---:|---:|---:|
| 공휴일·기상 추가 Random Forest | 0.833 | 0.722 | 0.774 | 0.850 |
| 기존 입력 Random Forest | 0.831 | 0.721 | 0.772 | 0.847 |

## 결론

외부 변수 추가 모델의 검증 MAE는 기존 입력 모델보다 0.28만큼 개선했다. 이 결과만으로 이미 보관 시험을 평가한 최종 모델을 다시 선택하지 않는다.

기상값은 천안 각 교차로의 현장 관측이 아닌 격자 재분석 자료다. 실제 서비스에서는 1시간 후 대상 시각에 사용할 수 있는 예보값으로 교체해야 한다.
