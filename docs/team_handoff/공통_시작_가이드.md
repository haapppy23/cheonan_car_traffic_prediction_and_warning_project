# 공통 시작 가이드

## GitHub 공동작업 권한

김성현이 먼저 팀원의 GitHub 사용자명을 받는다. 저장소의 `Settings`에서 `Collaborators` 또는 `Collaborators and teams`로 들어가 팀원을 추가한다. 팀원은 이메일이나 GitHub 알림으로 온 초대를 수락해야 같은 저장소에 본인 브랜치를 push할 수 있다.

초대를 수락한 팀원은 Git 이름과 이메일을 확인한다.

```powershell
git config user.name
git config user.email
```

값이 없다면 본인 정보로 설정한다. 커밋에 남길 이메일은 GitHub 계정 이메일이나 GitHub 비공개 이메일을 사용한다.

```powershell
git config --global user.name "본인 GitHub 이름"
git config --global user.email "본인 이메일"
```

## 저장소를 처음 받는 경우

PowerShell에서 작업할 폴더로 이동한 뒤 실행한다.

```powershell
git clone https://github.com/haapppy23/cheonan_car_traffic_prediction_and_warning_project.git
cd cheonan_car_traffic_prediction_and_warning_project
python -m pip install -r requirements.txt
```

AI 코딩 도구를 사용할 때는 clone한 `cheonan_car_traffic_prediction_and_warning_project` 폴더 자체를 작업 폴더로 연다. 그 상태에서 본인 이름의 프롬프트 파일 내용을 새 대화에 그대로 붙여 넣는다. 저장소 밖의 빈 폴더나 ZIP 파일을 직접 작업 폴더로 열지 않는다.

## 이미 저장소가 있는 경우

본인 변경이 없는지 먼저 확인하고 최신 `main`을 받는다.

```powershell
git status
git switch main
git pull --ff-only origin main
python -m pip install -r requirements.txt
```

`git status`에 본인이 만든 변경이 보이면 삭제하지 말고 먼저 별도 커밋하거나 김성현에게 알린다.

## 실행파일 압축 풀기

김성현에게 받은 `천안교통_실행파일.zip`을 저장소 최상위 폴더에 푼다. PowerShell을 사용한다면 저장소 최상위에서 다음과 같이 실행할 수 있다.

```powershell
Expand-Archive -LiteralPath '다운로드한_경로\천안교통_실행파일.zip' -DestinationPath . -Force
```

다음 파일이 보여야 한다.

```text
models/final_random_forest.joblib
data/processed/selected_traffic_long.csv
data/processed/features/high_traffic_thresholds.csv
```

이 파일들은 `.gitignore`로 제외되어 있으므로 `git add -f`로 강제 추가하지 않는다.

## 공통 확인

```powershell
python -m pytest -q
python -m uvicorn backend.app:app --reload
```

브라우저에서 `http://127.0.0.1:8000/docs`를 열고 `/health`와 `/predict`를 확인한다. 서버 종료는 실행한 PowerShell에서 `Ctrl+C`를 누른다.

## 개인 브랜치

이나율은 다음 브랜치를 사용한다.

```powershell
git switch -c feat/backend-locations
```

김문일은 이나율 작업이 `main`에 반영된 후 최신 `main`에서 다음 브랜치를 만든다.

```powershell
git switch -c feat/streamlit-ui
```

작업이 끝나면 본인 브랜치만 올린다.

```powershell
git push -u origin 현재_브랜치명
```

`main`에는 직접 push하지 않는다. 브랜치 주소와 커밋 해시, 테스트 결과를 김성현에게 전달한다.
