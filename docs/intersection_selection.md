# 모델링 대상 교차로 선정

2024년 1월 1일부터 2026년 8월 31일까지의 스마트교차로 교통량을 병합한 뒤 불당·두정·천안역·터미널 생활권에서 12개 교차로를 선정했다.

선정 결과는 교차로 12개, 접근로 44개, 와이드 형식 42,856행, 롱 형식 1,028,544행이다.

## 선정 기준

- 제안서에서 정한 불당·두정·천안역·터미널 생활권을 포함한다.
- 교차로의 모든 접근로가 전체 974일 중 99% 이상 관측되어야 한다.
- 실제 선정된 12개 교차로는 모든 접근로의 관측률이 100%이다.
- 시간대별 0값 비율과 24시간 전체 0인 접근로·날짜를 품질 지표로 함께 기록한다.
- 지역 대표성이 필요한 핵심 교차로는 품질 경고를 남긴 뒤 후속 EDA에서 이상 구간을 제외할지 판단한다.

## 제외 판단 사례

- `두정역사거리`와 `봉정사거리`는 2024년 12월 26일부터 관측되어 전 기간 관측률이 약 63.0%이므로 제외했다.
- `시청4`는 전 기간 관측되지만 시간값 0 비율이 약 29.6%이므로 제외했다.
- `터미널4`는 핵심 생활권을 직접 나타내므로 포함했지만 시간값 0 비율이 약 12.8%라 품질 경고 대상으로 분리했다.

## 재생성 방법

```bash
python src/data/prepare_monthly_traffic.py
python src/data/select_intersections.py
```

선정 목록은 `config/selected_intersections.csv`에서 관리한다. 자동 생성 결과는 `data/processed`에 저장되며 Git에는 포함하지 않는다.
