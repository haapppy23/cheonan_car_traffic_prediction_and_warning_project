# docs

데이터 구조, 실험 설계와 담당자 학습 설명서를 보관한다.

- `intersection_selection.md`: 모델링 대상 12개 교차로와 선정 근거
- `eda_report.md`: 선정 자료 102만여 행의 품질과 시간 패턴 분석
- `feature_dataset.md`: 누출 없는 입력 변수와 시간순 분할 생성 결과
- `baseline_results.md`: 시험 구간을 제외한 단순 기준 검증 결과
- `ridge_results.md`: Ridge와 단순 기준의 검증 성능 비교
- `hist_gradient_boosting_results.md`: 첫 트리 기반 후보와 Ridge 비교
- `high_traffic_alert_results.md`: 최고 회귀 모델의 고교통량 경보 지표
- `error_analysis.md`: 교차로·시간대별 오차와 놓친 고교통량 분석
- `random_forest_results.md`: Random Forest와 기존 후보의 검증 비교
- `random_forest_alert_results.md`: Random Forest의 고교통량 경보 지표
- `random_forest_error_analysis.md`: Random Forest의 교차로·시간대별 오류
- `final_test_results.md`: 최종 모델 선정 근거와 보관 시험 구간 성능
- `model_handoff.md`: 백엔드·프론트엔드 전달용 모델 입출력 규격
- `team_handoff/`: GitHub 연결법, 팀원별 AI 프롬프트와 전달문
