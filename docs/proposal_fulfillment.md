# 제안서 구현 대조

## 완료한 핵심 범위

- 불당·두정·천안역·터미널 생활권의 12개 교차로와 44개 접근로 선정
- 하루 24시간 열을 시간당 한 행으로 변환하고 관측률·0값·연속성 점검
- 1시간 후 교통량 회귀와 학습 구간 90백분위수 초과 경보 정의
- 단순 기준, Ridge, HistGradientBoosting, Random Forest, XGBoost, CatBoost 비교
- 시간순 학습·검증·보관 시험 분리와 Randomized Search
- MAE·WAPE·RMSE 및 Precision·Recall·F1·PR-AUC 평가
- Bias–Variance, 교차로·시간대·주말·강수 여부별 오류, SHAP 분석
- FastAPI 예측 API와 Streamlit 교차로 선택형 화면 구현
- 예상 교통량, 고교통량 위험, 최근 24시간 추세, 주요 영향 변수와 한계 표시

## 제안 단계에서 변경한 사항

### 기상 자료 출처

제안서에는 기상청 시간별 자료를 적었으나 실제 보충 실험은 천안 중심 좌표의 Open-Meteo 시간별 재분석 자료를 사용했다. 재현 가능한 자동 수집 코드를 함께 남겼으며, 이 값이 개별 교차로의 현장 관측이 아니라는 한계를 보고서에 명시한다.

### 공휴일·기상 효과

공휴일과 기상 변수는 같은 보충 모델에 함께 추가해 기존 Random Forest와 비교했다. 따라서 두 변수군의 결합 효과는 확인했지만 공휴일과 기상의 개별 인과 효과를 분리해 주장하지 않는다.

### 다른 방향 교통량과 변화량

다른 방향의 같은 대상 시각 교통량은 예측 시점에 알 수 없는 값이므로 입력하면 미래 정보 누출이 된다. 과거 다른 방향 교통량은 추가할 수 있지만 이번 최종 입력에서는 재현 가능한 현재 접근로의 지연값과 이동 통계로 범위를 제한했다. 별도 변화량은 `lag_1`, `lag_2`, 최근 3·6시간 평균과 6시간 표준편차가 최근 흐름을 이미 표현하므로 최종 입력에서 제외했다.

## 해석 제한

- 결과는 속도나 통행시간을 사용하지 않은 `고교통량 위험`이며 실제 정체를 확정하지 않는다.
- 강수 여부별 분석은 검증 구간을 설명하기 위한 분석이며 최종 모델을 다시 선택하거나 시험 결과를 재튜닝하는 데 사용하지 않는다.
- SHAP은 모델의 계산 근거이지 실제 인과관계를 증명하지 않는다.
- 행사·사고·공사처럼 관측하지 않은 요인은 예측에 직접 반영되지 않는다.

## 최종 보고서 AI 활용 내역 초안

- 사용 도구: ChatGPT·Codex(OpenAI)
- 활용 내용: 아이디어와 문제 정의 정리, 데이터 수집·검증 코드 작성 보조, 오류 수정, 테스트와 문서 정리
- 활용 범위: 데이터·모델·서비스 구현 과정의 보조 도구로 사용하고 프로젝트의 문제 정의와 실험 해석은 팀이 검토
- 검토 여부: 원본 데이터, 실행 결과, 자동 테스트와 GitHub 변경 이력을 기준으로 생성 코드와 수치를 직접 확인
