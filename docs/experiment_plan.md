# 실험 계획

## 현재 상태

실제 교통량 수집·검사, 와이드·롱 변환, 교차로 선정, EDA, 입력 변수 생성과 시간순 분할까지 완료했다. 고정 Ridge의 검증 결과는 MAE 62.43대, WAPE 10.66%, RMSE 111.58대로 단순 기준보다 개선되었다. 시험 구간은 아직 평가하지 않았다.

## 예측 대상

주 타깃은 접근로별 1시간 후 교통량이다.

보조 결과는 1시간 후 교통량이 해당 접근로의 학습 기간 교통량 90백분위수를 초과하는지 여부이다. 90백분위수는 시험 데이터를 보지 않고 학습 기간에서만 계산한다. 실제 양성 비율과 활용 목적을 확인한 뒤 85·95백분위수 민감도 분석을 추가할 수 있다.

## 시간순 데이터 분할

| 구간 | 기간 | 목적 |
|---|---|---|
| 학습 | 2024년 1월~2025년 12월 | 모델 학습과 전처리 기준 계산 |
| 검증 | 2026년 1월~5월 | 모델 선택과 하이퍼파라미터 탐색 |
| 시험 | 2026년 6월~8월 | 최종 성능 보고 |

실제 데이터 품질과 확보 기간에 따라 경계일을 조정할 수 있으나 과거에서 미래로 향하는 순서는 유지한다. 시험 데이터는 최종 모델이 확정되기 전까지 반복적으로 확인하지 않는다.

## 단순 기준

| 기준 | 예측 방법 | 목적 |
|---|---|---|
| 지속성 | 다음 시간도 현재 시간과 같다고 예측 | 가장 가까운 시점 기준 |
| 일간 계절성 | 전날 같은 시간 값 사용 | 하루 반복 패턴 기준 |
| 주간 계절성 | 전주 같은 요일·시간 값 사용 | 일주일 반복 패턴 기준 |
| 시간대 평균 | 학습 기간의 접근로·요일·시간 평균 | 통계적 기준 |
| Ridge | 시간과 과거 교통량을 사용한 선형 회귀 | 선형 모델 기준 |

복잡한 모델은 최소한 지속성과 주간 계절성 기준보다 검증 기간에서 안정적으로 좋아야 한다.

## 입력 변수 후보

| 그룹 | 후보 |
|---|---|
| 시간 | hour, day_of_week, month, is_weekend, is_holiday |
| 주기 표현 | hour_sin, hour_cos, weekday_sin, weekday_cos |
| 과거 교통량 | lag_1, lag_2, lag_3, lag_24, lag_168 |
| 최근 흐름 | rolling_mean_3, rolling_mean_6, rolling_std_6 |
| 공간·방향 | intersection, approach |
| 외부 환경 | temperature, precipitation, wind_speed |

3시간과 6시간 이동 평균은 짧은 변화와 조금 더 완만한 최근 흐름을 비교하기 위한 초기 후보이다. 고정된 정답이 아니며 실제 검증 결과에 따라 다른 시간 창을 비교할 수 있다. 후보를 무제한으로 추가하지 않고 선택 근거를 기록한다.

## 비교 모델

| 모델 | 비교 목적 |
|---|---|
| Ridge | 규제가 포함된 선형 기준 |
| Random Forest | 비선형성과 변수 상호작용 확인 |
| HistGradientBoosting | 많은 표 형태 행을 효율적으로 학습 |
| XGBoost | 규제와 정교한 부스팅 후보 |
| CatBoost | 교차로·접근로 같은 범주형 변수 처리 후보 |

모든 모델을 서비스에 동시에 넣는 것이 아니다. 동일한 학습 데이터와 시간순 검증 구간에서 각 모델을 비교한 뒤 오차와 안정성을 기준으로 최종 모델 하나를 선택한다. 성능 차이가 작으면 복잡도가 낮은 모델을 선택할 수 있다.

## 회귀 평가 지표

| 지표 | 확인하는 내용 | 방향 |
|---|---|---|
| MAE | 평균적으로 차량을 몇 대 틀렸는가 | 낮을수록 좋음 |
| WAPE | 전체 교통량 대비 절대오차 비율 | 낮을수록 좋음 |
| RMSE | 큰 예측 오차가 얼마나 발생했는가 | 낮을수록 좋음 |

교통량이 0인 시간이 있을 수 있으므로 MAPE는 주 지표로 사용하지 않는다.

## 고교통량 평가 지표

| 지표 | 확인하는 내용 | 방향 |
|---|---|---|
| Recall | 실제 고교통량을 얼마나 놓치지 않았는가 | 높을수록 좋음 |
| Precision | 발생시킨 경보가 얼마나 정확했는가 | 높을수록 좋음 |
| F1 | Recall과 Precision의 균형 | 높을수록 좋음 |
| PR-AUC | 경보 기준 변화 전체의 Precision·Recall 관계 | 높을수록 좋음 |

고교통량은 일반 시간보다 적게 발생하므로 단순 정확도만 보고 모델을 선택하지 않는다.

## 하이퍼파라미터 탐색

Randomized Search는 데이터를 무작위로 섞는 방법이 아니다. 데이터 시간 순서는 유지하고 트리 깊이, 트리 개수와 학습률 같은 설정 조합만 무작위로 골라 비교한다. 탐색 범위와 선택 근거를 보고서에 기록한다.

## 오류 분석 계획

- 출퇴근 시간과 비출퇴근 시간
- 평일, 주말, 공휴일과 강수일
- 교차로와 접근로별 MAE
- 가장 큰 과소예측과 과대예측 사례
- 고교통량을 놓친 False Negative 사례
- 센서 결측, 장기 0값과 명칭 변경의 영향

## 최종 서비스 출력

최종 서비스는 사용자가 선택한 교차로, 접근로와 기준 시각을 바탕으로 시스템이 과거 교통량과 시간 특성을 자동 생성한다. 저장된 모델은 1시간 후 예상 교통량, 접근로별 평상시 범위와 고교통량 위험을 반환한다. 사용자가 과거 교통량과 날씨 숫자를 직접 입력하는 구조는 아니다.
