# 데이터 구조와 품질 규칙

## 문서 상태

이 문서는 공개 페이지와 제안 단계에서 확인한 예상 구조를 기준으로 작성했다. 실제 월별 원본을 확보하면 열 이름, 자료형과 값의 범위를 다시 확인하고 변경 근거를 기록한다.

## 가공 전 와이드 형식

원본 한 행은 특정 날짜·교차로·접근로의 하루 교통량을 나타낸다.

| 열 | 예상 자료형 | 의미 | 필수 여부 |
|---|---|---|---|
| `일자` | 날짜 또는 문자열 | 관측 날짜 | 필수 |
| `교차로명` | 문자열 | 스마트교차로 위치명 | 필수 |
| `접근로명` | 문자열 | 진입 방향을 포함한 접근로 이름 | 필수 |
| `합계` | 정수 또는 실수 | 하루 교통량 합계 | 선택 |
| `00시`~`23시` | 정수 또는 실수 | 각 시간대의 차량 통행량 | 필수 |

합계는 검사에 유용하지만 시간대 값으로 다시 계산할 수 있으므로 변환의 필수 키로 사용하지 않는다.

실제 원본의 열 이름이 `날짜`, `교차로`, `진입로`처럼 다르면 명령행 옵션으로 명시한다. 알 수 없는 열을 자동으로 추측하여 처리하지 않는다.

## 가공 후 롱 형식

가공 후 한 행은 특정 교차로·접근로·시각의 한 시간 교통량을 나타낸다.

| 열 | 자료형 | 의미 | 생성 시점 |
|---|---|---|---|
| `timestamp` | datetime | 일자와 시각을 합친 관측 시각 | 와이드·롱 변환 |
| `intersection` | string | 교차로명 | 와이드·롱 변환 |
| `approach` | string | 접근로명 | 와이드·롱 변환 |
| `volume` | numeric | 해당 한 시간의 교통량 | 와이드·롱 변환 |
| `date` | date | 날짜 | 와이드·롱 변환 |
| `hour` | int | 0~23 시각 | 와이드·롱 변환 |
| `day_of_week` | int | 월요일 0부터 일요일 6 | 와이드·롱 변환 |
| `is_weekend` | bool | 토요일 또는 일요일 여부 | 와이드·롱 변환 |
| `is_holiday` | nullable bool | 공휴일 여부 | 외부 공휴일 정보 결합 |

현재 변환 코드는 공휴일 정보를 임의로 추정하지 않는다. 외부 공휴일 자료를 결합하기 전 `is_holiday`는 결측값으로 둔다.

## 고유 키와 중복

원본의 예상 고유 키는 다음 조합이다.

```text
일자 + 교차로명 + 접근로명
```

롱 형식의 고유 키는 다음 조합이다.

```text
timestamp + intersection + approach
```

같은 키가 두 번 존재하면 어떤 값이 정답인지 코드가 임의로 선택하지 않는다. 원본 중복인지, 합산 대상인지, 명칭이 다른 지점인지 확인한 뒤 처리 규칙을 정한다.

## 결측값 처리 원칙

- 정답인 `volume`이 없는 행은 임의로 채워 학습하지 않는다.
- 결측률과 연속 결측 길이를 접근로별로 기록한다.
- 짧은 결측을 보정해야 한다면 학습·검증·시험 분리 이후 과거 정보만 사용하는 방법을 적용한다.
- 전체 데이터의 평균으로 검증·시험 데이터를 미리 채우지 않는다.
- 결측 처리 방법과 처리된 행 수를 실험 기록에 남긴다.

## 음수와 0값

- 음수 교통량은 정상값으로 보지 않고 원본을 재확인한다.
- 한두 시간의 0은 실제 저교통량일 수 있으므로 자동 삭제하지 않는다.
- 여러 시간 또는 여러 날 연속된 0은 센서 중단이나 도로 통제 가능성을 별도로 확인한다.
- `inspect_raw.py`는 음수 셀 수, 전체 0 셀 수, 하루 전체가 0인 행 수와 한 행의 최대 연속 0시간을 보고한다.

## 교차로·접근로 명칭 변경

- 공백, 괄호와 방향 표기의 차이를 먼저 확인한다.
- 실제 같은 지점이라는 근거가 있을 때만 표준 명칭 매핑표를 만든다.
- 이름이 비슷하다는 이유만으로 자동 병합하지 않는다.
- 신규 운영 지점과 중단 지점은 운영 기간을 기록한다.

## 데이터 누출 방지

- 한 시간 후 교통량을 예측할 때 해당 시점 이후의 교통량을 입력으로 사용하지 않는다.
- 결측 대체값, 스케일러와 90백분위수는 학습 기간에서만 계산한다.
- 실제 서비스에서 알 수 없는 미래 관측 날씨를 기본 성능 실험에 사용하지 않는다.
- 시험 기간은 최종 모델이 확정된 뒤 한 번 평가한다.
