# HistGradientBoosting 고교통량 경보 검증 결과

## 평가 기준

HistGradientBoosting가 예측한 교통량이 해당 접근로의 학습 구간 90백분위수를 초과하면 경보로 판단했다. PR-AUC 점수는 `예측 교통량 ÷ 접근로별 기준값`을 사용했다. 이 점수는 확률이 아니라 서로 다른 접근로의 기준을 맞춘 상대 위험 점수이다.

- 검증 행: 156,552개
- 실제 고교통량: 12,217건, 7.80%
- 발생 경보: 10,195건, 6.51%
- 시험 구간: 사용하지 않음

## 경보 지표

| Precision | Recall | F1 | PR-AUC |
|---:|---:|---:|---:|
| 0.815 | 0.680 | 0.742 | 0.815 |

| 놓친 고교통량, FN | 3,907 |
| 정상 시간을 정상으로 판단, TN | 142,450 |

## 해석 원칙

현재 결과는 학습 구간에서 정한 90백분위수를 그대로 적용한 기준선이다. Recall을 높이기 위해 임의로 경보 기준을 낮추지 않았으며, 기준 조정이 필요하면 검증 구간에서 별도 비교한 뒤 결정한다.
